# קלפי היסודות · FusGame

משחק קלפים בסגנון *Little Alchemist* — מצרפים שני קלפים כדי לגלות שלישי, בונים
מהאוסף חפיסה, ויוצאים איתה לקרבות תורות מול שנים־עשר יריבים.

אין תלויות ואין שלב בנייה. פותחים את `index.html` בדפדפן וזהו.

---

## המשחק

**המעבדה** — מתחילים עם ארבעה יסודות: אש, מים, אדמה, אוויר. מניחים שניים על
השולחן; אם קיים ביניהם מתכון, נולד קלף שלישי. 81 קלפים, 77 מתכונים, שבע דרגות —
מ־*אש + מים = קיטור* ועד *גביש + בראשית = אבן החכמים*. כל הקלפים ניתנים לגילוי
מארבעת היסודות בלבד (נבדק אוטומטית ב־`tools/validate.mjs`).

**הקודקס** — האוסף כולו, מסודר בדרגות. קלפים שטרם התגלו נשארים כצללית, כדי
שתמיד יהיה ברור כמה נשאר.

**החפיסה** — 20 קלפים. יסודות עד ×4, ראשוניים ומורכבים ×3, גבוהים ×2, אגדיים ×1.
יש בונה אוטומטי שמפזר בין הדרגות, כדי שתמיד יהיה חומר גלם ליד להיתוך.

**הקרב** — קרב קלפים חשאי־סימולטני, בהשראת Little Alchemist: Remastered. יד
של 5 קלפים, 30 חיים לגיבור. כל סיבוב שני הצדדים בוחרים בסתר קלף אחד לתקיפה —
או שני קלפים להיתוך לקלף חזק יותר, באמצעות אותו עץ המתכונים של המעבדה — ואז
נחשפים יחד. תקיפה: הפרש בין ההתקפה של קלף אחד להגנה של השני פוגע בגיבור
היריב. היתוך: קלף בסיסי + כל דבר עולה 3 אורבים ("צורה סופית"); שני קלפים
שכבר הותכו קודם מתאחים בחינם ("Mega", עם בונוס קטן) — אבל מי שמתיך לא מגן על
עצמו באותו סיבוב. שלוש מחלקות: יסודן (בונוס התקפה שנצבר על רצף היתוכים,
ומתאפס בתקיפה), מכשף חפצים (הוצאת אורבים על באף זמני לקלף שמשחקים), מרפא
(הוצאת אורבים על ריפוי עצמי). בוחרים מחלקה לפני כל קרב, מהמסך של המסע.

**התקדמות** — ניצחון מזכה בזהב וברסיס של קלף אקראי מהאוסף. שלושה רסיסים = דרגה,
וכל דרגה נותנת ‎+1/+1 קבוע לקלף. הזהב קונה רמזים (חשיפת מתכון) וצרורות רסיסים.

ההתקדמות נשמרת ב־`localStorage` של הדפדפן. לחיצה כפולה על הלוגו פותחת סטטיסטיקות
ואיפוס.

## הרצה

```bash
# כל שרת סטטי, למשל:
python3 -m http.server 8000
# ואז http://localhost:8000
```

פתיחה ישירה של `index.html` דרך `file://` לא תעבוד בגלל מדיניות CORS על ES
modules — צריך שרת, גם אם מקומי.

## בדיקות

```bash
node tools/validate.mjs   # תקינות מסד הקלפים
node tools/sim.mjs 10     # 1320 קרבות AI מול AI
npm i && node tools/smoke.mjs   # מעבר מלא בדפדפן (מובייל + דסקטופ)
```

* **validate** — מוודא שאין התנגשויות מתכונים, שכל קלף ניתן להגעה מארבעת
  היסודות, שאין הפניות שבורות, ושחפיסה חוקית ניתנת לבנייה כבר מדרגות 0–1.
* **sim** — משחק כל חפיסת קמפיין נגד כל אחת אחרת, ובודק שהמנוע מסתיים תמיד ושעקומת
  הקושי עולה לאורך המסע.
* **smoke** — Playwright: מגלה קלף, בונה חפיסה, משחק קרב שלם עד הכרעה, ומוודא
  שאין שגיאות קונסולה ואין גלישה אופקית בשני גדלי מסך.

## מבנה

```
index.html
css/
  theme.css         אסימוני עיצוב — פלטה, טיפוגרפיה, גאומטריה
  app.css           רכיבי הממשק
js/
  data/cards.js     81 קלפים ומתכונים
  data/campaign.js  12 יריבים, כל אחד עם מחלקה
  core/battle.js    מנוע קרב חשאי־סימולטני (ללא DOM, ניתן לבדיקה ב־Node)
  core/ai.js        יריב עיוור — מחליט בלי לראות את הבחירה של השחקן
  core/state.js     שמירה, גילויים, רסיסים, חפיסה, מחלקה מועדפת, התקדמות
  ui/sigil.js       דיוקן מפלצת פרוצדורלי לכל קלף
  ui/card.js        רינדור קלף
  ui/dom.js         עזרי DOM, טוסטים, מודאלים
  screens/          מעבדה · קודקס · חפיסה · מסע · קרב
  main.js           נתב ואתחול
tools/              validate · sim · smoke
DESIGN.md           פילוסופיית העיצוב
```

**המפלצות** — לכל קלף יש מפלצת משלו, שנגזרת דטרמיניסטית מה־id שלו: גוף,
קרניים, כנפיים ופרצוף נבנים כולם מ־RNG זרוע. היסוד קובע את המזג — גוף עגול
ורגוע למים/חיים/אדמה, גוף מקוטע וחד לאש/נסתר/מתכת — כך שאפשר לזהות יסוד
מהצללית בלבד, בדיוק כפי שקודם זוהה מהצבע. הצפיפות עולה עם הדרגה: יותר
קרניים, יותר קשקשים, ורק המפלצות העתיקות ביותר זוכות לכתר. על החזה נשאר
סימן קטן ודהוי — הרמז האחרון לזהות היסוד המקורית שהמשחק דיבר בה. אין קובצי
תמונה בפרויקט.

## עיצוב

**מערכת העיצוב מועתקת מ־[THE-ARENA](https://github.com/Ld2000king/THE-ARENA)** —
אובסידיאן מט בנטייה סגלגלה, שוליים מתכתיים (קצה עליון תופס אור, תחתון שוקע),
כפתורים יצוקים שנדחסים בלחיצה, פינות מעוגלות 14–28px, וזוג הפונטים Rubik +
Poppins. הטוקנים ב־`css/theme.css` הועתקו מילה במילה מ־`styles.css` שם, כדי
ששני המשחקים ייראו כמו משפחה אחת.

מה שנוסף כאן ולא קיים שם: המיפוי של שמונת היסודות ושבע הדרגות אל הפלטה.
שישה יסודות נופלים ישירות על גוון של THE-ARENA; אוויר ומתכת נגזרו באותה שפה
כי אין להם מקבילה. חמשת צבעי הנדירות שם נמתחו לשבע דרגות לאורך אותו רצף
אפור ← כחול ← סגול ← ענבר ← ארגמן.

**העיקרון שנשמר:** לכל יסוד גוון אחד משלו — הצבע הוא מערכת המידע הראשית,
ואפשר לזהות יסוד של קלף מקצה החדר בלי לקרוא מילה. הפילוסופיה המלאה
ב־[`DESIGN.md`](DESIGN.md).
